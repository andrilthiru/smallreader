# Tamil Interactive Small Readers — Samples

Samples for the Tamil interactive small readers ITQ (Primary 3).

- **Home page:** `index.html` (GitHub Pages)
- **E-book samples:** `samples/` — Version 2 (latest, HTML5) and Version 1 (earlier, Storyline 360). Both are SCORM 1.2 and run offline.
- **SCORM packages:** `downloads/`
- **Features document:** `docs/features.pdf`
- **Voice-over samples:** `voiceovers/` — to add one, put the audio file there and add a line to `voiceovers/list.js`.
